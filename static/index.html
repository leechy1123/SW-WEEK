YOUR FIRST SECURITY CHECK

처음 시작하기

코딩을 몰라도 결과를 비교할 수 있어요. 준비된 예제로 시작하세요.

01

문제를 직접 만나기

대시보드에서 수정 전을 선택하고 확인란에 체크한 뒤 진단 시작을 누르세요.

실습 사이트에서는 남의 글을 열고, 오류 화면을 보고, 검색 결과를 바꿔볼 수 있습니다.

02

왜 문제인지 이해하기

결과를 펼치면 발견 위치 → 확인한 근거 → 수정 방법을 볼 수 있습니다.

200은 응답 성공, 401은 로그인 필요, 403은 권한 없음, 500은 서버 오류를 뜻해요. 상태 숫자만으로 취약점을 단정하지 않습니다.

03

수정 결과 비교하기

수정 전후 한 번에 비교를 누르면 동일한 요청으로 두 버전을 점검합니다.

수정 후에는 남의 글이 차단되고, 내부 오류는 숨겨지며, 검색어는 명령으로 실행되지 않습니다.

04

내 손으로 고쳐보기

VS Code에서 lab.py를 열고 REPAIR_ACCESS = False를 True로 바꿔보세요.

서버를 종료하고 다시 실행한 후 수정 전을 재진단하면 A01이 통과로 바뀝니다. 나머지 두 항목도 같은 방식으로 연습하세요.

알아두면 좋은 네 가지 단어

URL
웹페이지의 주소입니다. 이 실습의 127.0.0.1은 내 컴퓨터를 뜻해요.
서버
브라우저의 요청을 받아 결과를 돌려주는 프로그램입니다.
SQL
데이터베이스에서 정보를 찾거나 저장하는 명령입니다.
매개변수 바인딩
명령과 데이터를 따로 전달해 입력이 명령이 되지 않게 하는 방법입니다.
